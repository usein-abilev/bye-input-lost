# Bye Input Lost
Bye Input Lost is a Chrome extension that stores user input text to prevent data loss when accidentally closing a page or tab.

## Features
- **Automatic Input Tracking**: Monitors text inputs, textareas, and content-editable elements on web pages
- **Local Storage**: All data is stored locally in the browser - nothing is sent to external servers
- **Page Notifications**: Shows a notification when you revisit a page with saved drafts
- **Popup Interface**: View and manage saved drafts for the current page

## How to Use

### Automatic Saving

The extension automatically saves your input as you type. When you return to a previously visited page:
1. If notifications are enabled, a notification will appear showing the number of saved inputs
2. Click "Restore" to restore your text to the input fields
3. Click "Discard" to remove the saved data

### Using the Popup

1. Click the extension icon in the Chrome toolbar
2. The popup displays saved drafts for the current page only
3. Click "Restore" to restore text to the page
4. Click "Remove" to delete individual drafts

### Settings

In the popup, you can toggle "Show notification on page visit" to enable or disable notifications when returning to pages with saved drafts.
